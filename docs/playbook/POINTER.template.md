> **วิธีใช้ไฟล์นี้:** ก๊อปเนื้อหาใต้เส้นคั่นไปเป็นไฟล์ที่เครื่องมือของทีม auto-load (ดูตารางข้างล่าง) ทำ **1 ไฟล์ต่อ 1 เครื่องมือที่ใช้จริง** แล้วแทนที่ `<...>` — จากนั้น **ลบกล่องนี้และตารางทิ้ง**
>
> **หลักการ (base §9.1):** ของจริงมีที่เดียวคือ canonical (`AGENTS.md` จาก `AGENTS.template.md`) ไฟล์อื่นเป็น **pointer 2–3 บรรทัด** เท่านั้น
>
> - **ห้ามก๊อปเนื้อหาของ canonical มาวางซ้ำ** — จะกลายเป็นกฎ 2 ชุดที่ drift กัน (base §5.10)
> - **ห้ามใช้ symlink แทน pointer** — พังเวลา checkout บนระบบที่ไม่รองรับ และเครื่องมือบางตัวไม่ตามลิงก์
> - pointer ต้องเป็น **คำสั่งให้ไปอ่าน** ไม่ใช่แค่บอกว่ามีไฟล์นั้นอยู่ + ย้ำข้อห้ามที่ราคาแพงที่สุด **1 ข้อ** เผื่อ agent ไม่เปิด canonical (defense-in-depth) เกินกว่านั้นให้อยู่ใน canonical เท่านั้น
> - ประกาศใน `PLAYBOOK.md` (`R1`) ว่า canonical คือไฟล์ไหนและมี pointer อะไรบ้าง เพื่อไม่ให้ใครเผลอแก้ pointer แทน canonical
>
> **ชื่อไฟล์ที่เครื่องมือ auto-load** — ตรวจกับเอกสารของเวอร์ชันที่ทีมใช้จริง รายการนี้เปลี่ยนตามเครื่องมือ ไม่ใช่กฎของ playbook · **ทำเฉพาะไฟล์ของเครื่องมือที่ทีมใช้จริง** ไฟล์ pointer ที่ไม่มีใครใช้คือขยะที่ต้องตามอัปเดต:
>
> | เครื่องมือ | ไฟล์ที่โหลดอัตโนมัติ |
> |---|---|
> | convention ข้ามเครื่องมือ (Codex CLI และอื่น ๆ) | `AGENTS.md` ← **canonical ปกติอยู่ที่นี่ ไม่ต้องทำ pointer** |
> | Claude Code | `CLAUDE.md` |
> | Qwen Code / Gemini CLI | `QWEN.md` / `GEMINI.md` |
> | GitHub Copilot | `.github/copilot-instructions.md` |
